# 时间之锚

网页挂机游戏。2300 年，三体舰队抵达地球近地空间。你的导师把「时间之锚」芯片植入义体，把你送上一颗智子看不见的遥远星球。从一条河边开始，重建文明，并在危机落下前返回地球。

## 给朋友玩

上线后把这个地址发给他们：

https://fisheren.github.io/time-anchor/

他们用手机或电脑打开后：

- **iPhone / iPad**：Safari 打开 → 分享 → 添加到主屏幕
- **Android**：Chrome 打开 → 菜单 → 安装应用 / 添加到主屏幕
- **电脑**：Chrome / Edge 地址栏右侧的安装图标，或游戏「设置 → 安装到主屏幕」

装好后主屏幕会有一个「时间之锚」图标，和普通 App 一样打开。你这边一更新并推送，他们下次打开会自动获取新版本。存档在每个人自己的设备上，互不影响。

## 你怎么更新

改完游戏后告诉我「发布更新」，或自己执行：

```bash
# 改 sw.js 里的 VERSION（每次发布都要改，朋友才能收到更新）
git add -A
git commit -m "更新时间之锚"
git push
```

GitHub 一两分钟后会自动部署。朋友再打开应用就会同步。

## 本地运行

```bash
python3 -m http.server 8080
```

访问 `http://localhost:8080`。

## 玩法

- **河岸**：汲水、采集，解码「用火」，建造营地。
- **聚落**：居民迁入后分配职业。建造专属居所，消耗清水与食物抽签招募高级居民。抽中后可留下、放弃或再抽一次，已入驻者可遣返。注意食物与霜降季。
- **探索**：高级居民组成至多五人的小队，每次进入一个区块。前往、探索、返回三段行程；物资装满或战斗失败会自动返回。越远越慢，制造木筏、板车、河舟、蒸汽车、浮橇缩短路程。
- **工坊**：加工材料、一次性工艺升级。
- **智库**：解码芯片中的人类知识。
- **星空**：航天与隐蔽。朝宇宙大声说话会被智子看见。
- **锚点**：充能完毕后回溯到河边，保留「余烬」与铭刻。

存档写在本机。设置中可导出、导入或清空。离线最多结算 8 小时。
